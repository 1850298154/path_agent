# 右旋逃逸（右手定则）实现机制

## 1. 核心思想

通过**非对称调整**机器人间的排斥力系数，使机器人在死锁时产生向右侧绕行的趋势，从而打破死锁。

## 2. 核心公式

排斥力系数的自适应调整：

$$\gamma_{ij} = \gamma_0 e^{(\rho_i(t) \sin \theta_{ij})}$$

### 2.1 参数定义

| 符号 | 含义 | 说明 |
|------|------|------|
| $\theta_{ij}$ | 方向夹角 | 从机器人 $i$ 到目标方向与到机器人 $j$ 方向的夹角（xy平面内） |
| $\rho_i(t)$ | 死锁强度参数 | 随死锁持续时间单调递增 |
| $\gamma_0$ | 排斥力系数基数 | 正常数 |

### 2.2 角度约定

以机器人 $i$ 为原点，**到目标方向为 x 轴正方向**：

- **$\theta_{ij} > 0$**：机器人 $j$ 在机器人 $i$ 的**左手边**（y > 0）
- **$\theta_{ij} < 0$**：机器人 $j$ 在机器人 $i$ 的**右手边**（y < 0）

## 3. 右手定则工作机制

### 3.1 排斥力不对称调整

| 机器人 $j$ 位置 | $\sin\theta_{ij}$ | 指数项 $e^{(\rho_i \sin \theta_{ij})}$ | 效果 |
|----------------|-------------------|----------------------------------------|------|
| 左手边 ($\theta_{ij} > 0$) | 正 | **$> 1$** | 排斥力**增强** → 远离 $j$ |
| 右手边 ($\theta_{ij} < 0$) | 负 | **$< 1$** | 排斥力**减弱** → 靠近 $j$ |

### 3.2 物理直觉

当发生死锁时：

```
        左侧机器人 (θ > 0)
             ↑
             |  排斥力增强 (被推开)
             |
    目标 ←---●---→ 右侧机器人 (θ < 0)
    (x轴)       |
                 |  排斥力减弱 (可靠近)
                 ↓
```

1. 左侧排斥力**增强** → 机器人被推离左侧
2. 右侧排斥力**减弱** → 机器人向右侧移动
3. **净效果**：机器人整体产生向**右侧绕行**的趋势

## 4. 死锁检测与触发

### 4.1 终端重叠检测条件

同时满足以下 4 个条件时判定为死锁：

| 条件 | 公式 | 说明 |
|------|------|------|
| 1 | $p_i^K(t) = p_i^K(t-h)$ | 终端位置不变 |
| 2 | $p_i^K(t) \neq p_i^{target}$ | 未到达目标 |
| 3 | $p_i^K(t) = p_i^{K-1}(t)$ | 终端位置与前一个规划位置重合 |
| 4 | $p_i^{K-1}(t) = p_i^{K-2}(t)$ | 连续两个规划位置重合 |

### 4.2 死锁强度参数更新

$$\rho_i(t) = \begin{cases}
\rho_i(t-h) + \delta, & \text{if } b_i^{TO} = True \text{ (检测到死锁)} \\
0, & \text{if } w_{ij} = \epsilon, \forall j \neq i \text{ (脱离死锁)} \\
\rho_i(t-h), & \text{otherwise}
\end{cases}$$

其中：
- $\delta > 0$：死锁强度增量
- $b_i^{TO}$：终端重叠标志

## 5. 力学解释

死锁条件可理解为力平衡：

$$\underbrace{Q_K (p_i^{target} - p_i^K)}_{\text{吸引力}} + \underbrace{\sum_{j \in \mathcal{N}^i} \gamma_{ij} \frac{\alpha_{ij}}{w_{ij}} a_{ij}^K}_{\text{排斥力之和}} = 0$$

右手定则通过调整 $\gamma_{ij}$，使 y 方向的力平衡被打破：

$$F_y^i = \sum_{j \in \mathcal{N}^i} \sin \theta_{ij} \gamma_0 e^{\rho_i(t-h) \sin \theta_{ij}} \gamma_{ij} (1 - e^{\delta \sin \theta_{ij}}) \geq 0$$

当 $\rho_i$ 增大时，$F_y^i > 0$，机器人产生向右侧（y 正方向）的加速度，从而逃离死锁。

## 6. 代码实现伪代码

```python
def compute_gamma_ij(gamma_0, rho_i, theta_ij):
    """
    计算排斥力系数
    
    Args:
        gamma_0: 排斥力系数基数
        rho_i: 死锁强度参数
        theta_ij: 方向夹角 (rad)
    
    Returns:
        gamma_ij: 调整后的排斥力系数
    """
    return gamma_0 * np.exp(rho_i * np.sin(theta_ij))

def compute_theta_ij(p_i_K, p_target, p_j_K):
    """
    计算方向夹角
    
    Args:
        p_i_K: 机器人i的终端位置
        p_target: 机器人i的目标位置
        p_j_K: 机器人j的终端位置
    
    Returns:
        theta_ij: 方向夹角 (rad)
    """
    # 到目标的方向 (x轴)
    dir_to_target = p_target - p_i_K
    dir_to_target = dir_to_target / np.linalg.norm(dir_to_target)
    
    # 到机器人j的方向
    dir_to_j = p_j_K - p_i_K
    dir_to_j = dir_to_j / np.linalg.norm(dir_to_j)
    
    # 计算夹角 (使用atan2保证符号正确)
    theta_ij = np.arctan2(
        dir_to_j[1],  # y分量
        dir_to_j[0]   # x分量
    )
    
    return theta_ij
```

## 7. 典型参数设置

| 参数 | 典型值 | 说明 |
|------|--------|------|
| $\gamma_0$ | 2.0 | 排斥力系数基数 |
| $\delta$ | 0.2 | 死锁强度增量 |
| $\rho_{max}$ | 0.3 | 死锁强度上限 |

## 8. 总结

右手定则的关键创新：

1. **非对称性**：左右两侧排斥力不对称，产生侧向运动趋势
2. **自适应性**：$\rho_i$ 随死锁时间增长，自动调节逃逸力度
3. **一致性**：所有机器人都遵循相同的右手定则，避免振荡
4. **理论保证**：在温和条件下可证明不存在稳定死锁
