# 角度定义与力作用机制澄清

## 1. 角度 $\theta_{ij}$ 的定义

### 1.1 正确定义

$\theta_{ij}$ 是**两个方向向量的夹角**（有符号），不是单纯以全局 x 轴为基准。

$$\theta_{ij} = \angle(\vec{d}_{target}, \vec{d}_{j})$$

其中：
- $\vec{d}_{target} = p_i^{target} - p_i^K$：从机器人 $i$ 到目标的方向
- $\vec{d}_{j} = p_j^K - p_i^K$：从机器人 $i$ 到机器人 $j$ 的方向

### 1.2 局部坐标系视角

为便于理解，可以建立一个**局部坐标系**：

```
                y (正交方向)
                ↑
                |
                |    ● 机器人 j (θ > 0, 左侧)
                |   /
                |  / θ_ij
                | /
    目标 ←-----●-----→ x (到目标方向)
           机器人 i
                | \
                |  \ θ_ij
                |   \
                |    ● 机器人 j (θ < 0, 右侧)
                |
```

**以"到目标方向"为局部 x 轴正方向**，则：
- $\theta_{ij} > 0$：机器人 $j$ 在左侧（y > 0）
- $\theta_{ij} < 0$：机器人 $j$ 在右侧（y < 0）

### 1.3 计算公式

```python
def compute_theta_ij(p_i_K, p_target, p_j_K):
    # 到目标的方向向量
    d_target = p_target - p_i_K
    
    # 到机器人 j 的方向向量
    d_j = p_j_K - p_i_K
    
    # 有符号夹角计算
    # 方法1：使用 atan2
    angle_target = np.arctan2(d_target[1], d_target[0])
    angle_j = np.arctan2(d_j[1], d_j[0])
    theta_ij = angle_j - angle_target
    
    # 归一化到 (-π, π]
    theta_ij = np.arctan2(np.sin(theta_ij), np.cos(theta_ij))
    
    return theta_ij
```

## 2. 力的作用机制：不是直接加入目标方程

### 2.1 重要澄清

**排斥力不是直接作为"力"加入目标函数**，而是通过以下机制起作用：

| 层面 | 机制 |
|------|------|
| **优化问题** | $\gamma_{ij}$ 出现在目标函数 $C_{w_i}$ 中 |
| **KKT 条件** | 推导出力平衡方程 |
| **物理直觉** | 可理解为"虚拟力" |

### 2.2 目标函数结构

$$C_i = C_{p_i} + C_{w_i}$$

**位置惩罚项**（吸引力来源）：
$$C_{p_i} = \frac{1}{2}Q_K \|p_i^K - p_i^{target}\|^2 + \ldots$$

**警告带惩罚项**（排斥力来源）：
$$C_{w_i} = \sum_{j \neq i} \gamma_{ij}\left(\frac{w_{ij}}{\epsilon} - \ln w_{ij}\right)$$

### 2.3 KKT 条件推导力平衡

通过拉格朗日函数和 KKT 条件，最优解处满足：

$$\frac{\partial C_i}{\partial p_i^K} + \sum_{j} \lambda_{ij} \frac{\partial g_{ij}}{\partial p_i^K} = 0$$

代入具体形式，得到**力平衡方程**：

$$\underbrace{Q_K (p_i^{target} - p_i^K)}_{\text{吸引力（来自 } C_{p_i} \text{）}} + \underbrace{\sum_{j \in \mathcal{N}^i} \gamma_{ij} \frac{\alpha_{ij}}{w_{ij}} a_{ij}^K}_{\text{排斥力（来自 } C_{w_i} \text{）}} = 0$$

### 2.4 作用机制总结

```
┌─────────────────────────────────────────────────────────────┐
│                        优化问题                              │
│  min C_i = C_p_i + C_w_i                                    │
│  s.t. 碰撞约束、动力学约束等                                  │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                     求解优化问题                             │
│  调整 γ_ij → 影响 C_w_i → 改变最优解位置                     │
└─────────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                   KKT 条件（最优性条件）                      │
│  → 可解释为"力平衡"                                          │
│  → 吸引力 + 排斥力 = 0                                       │
└─────────────────────────────────────────────────────────────┘
```

## 3. 右手定则如何打破死锁

### 3.1 死锁时的状态

- 机器人静止：$u_i^{k-1} = 0$，$v_i^k = 0$
- 力平衡：吸引力 + 排斥力 = 0
- 未到达目标

### 3.2 调整 $\gamma_{ij}$ 的效果

当 $\rho_i$ 增大时：

| 位置 | $\gamma_{ij}$ 变化 | 排斥力变化 | 效果 |
|------|-------------------|-----------|------|
| 左侧 ($\theta > 0$) | 增大 | 增强 | 被推开 |
| 右侧 ($\theta < 0$) | 减小 | 减弱 | 可靠近 |

### 3.3 打破平衡

原来：$\sum \vec{F}_{排斥} = -\vec{F}_{吸引}$

调整后：y 方向排斥力变化 → y 方向力不再平衡 → 产生侧向运动

$$F_y^i > 0 \Rightarrow \text{向右移动}$$

## 4. 简化理解

可以把整个过程理解为：

1. **目标函数** $C_i$ 定义了机器人的"行为准则"
2. **$\gamma_{ij}$** 是这个行为准则中的一个**可调参数**
3. 通过调整 $\gamma_{ij}$，改变优化问题的最优解
4. **KKT 条件**提供了理解最优解的"力学视角"
5. **右手定则**是一种特定的参数调整策略，用于打破死锁

## 5. 关键区别

| 问题 | 回答 |
|------|------|
| $\theta_{ij}$ 以全局 x 轴为基准？ | **否**，以"到目标方向"为基准 |
| 排斥力直接加入目标方程？ | **否**，$\gamma_{ij}$ 在目标函数中，力平衡是 KKT 结果 |
| 如何产生作用？ | 改变优化问题的最优解位置 |
