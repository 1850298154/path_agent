# 目标函数与约束的协同作用

## 1. 各自职责

| 组件 | 作用 | 公式 |
|------|------|------|
| **目标函数** | 决定机器人"想去哪" | $\min C_i$ |
| **约束** | 限制机器人"能去哪" | $a_{ij}^k \cdot p_i^k \geq b_{ij}^k$ |

## 2. 协同机制

```
目标函数（吸引力）          约束（边界）
      ↓                        ↓
   "向目标移动"            "不能进入他人区域"
      ↓                        ↓
      └────────→ 优化求解 ←────────┘
                     ↓
              最优位置 p_i^K
```

## 3. 具体作用方式

### 3.1 目标函数：提供"拉力"

$$C_{p_i} = \frac{1}{2}Q_K \|p_i^K - p_i^{target}\|^2$$

- **作用**：最小化与目标的距离
- **效果**：像弹簧，把机器人"拉"向目标

### 3.2 约束 + 警告带惩罚：提供"推力"

**约束**（硬边界）：
$$a_{ij}^K \cdot p_i^K \geq b_{ij}^K + w_{ij}$$

**警告带惩罚**（软边界）：
$$C_{w_i} = \sum_{j \neq i} \gamma_{ij}\left(\frac{w_{ij}}{\epsilon} - \ln w_{ij}\right)$$

- **作用**：
  - 约束保证 $w_{ij} > 0$（不碰撞）
  - 目标函数惩罚小 $w_{ij}$（远离边界）
- **效果**：像弹簧，把机器人"推"离他人

## 4. 平衡状态（死锁）

当目标函数的"拉力"与警告带的"推力"平衡时：

$$\frac{\partial C_i}{\partial p_i^K} = 0$$

展开得：

$$Q_K \underbrace{(p_i^{target} - p_i^K)}_{\text{拉力}} + \sum_{j} \gamma_{ij} \underbrace{\frac{\alpha_{ij}}{w_{ij}} a_{ij}^K}_{\text{推力}} = 0$$

## 5. 右手定则的作用

通过**非对称调整** $\gamma_{ij}$，打破力平衡：

```
原来：拉力 = 推力（平衡/死锁）
调整后：左推力↑ 右推力↓ → 产生侧向净力 → 向右移动
```

## 6. 一句话总结

> **目标函数决定方向，约束决定边界，优化求解在边界内找最优位置，$\gamma_{ij}$ 调整"边界软硬"来打破死锁。**
