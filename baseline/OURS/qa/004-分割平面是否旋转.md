# 分割平面是否旋转？

## 1. 直接回答

**不是。分割平面本身不旋转，$\gamma_{ij}$ 调整的是边界的"软硬程度"。**

## 2. 分割平面的决定因素

分割平面（MBVC-WB）由**预定轨迹**决定：

$$a_{ij}^k = \frac{\bar{p}_i^k - \bar{p}_j^k}{\|\bar{p}_i^k - \bar{p}_j^k\|}$$

- $a_{ij}^k$：平面法向量（方向）
- $b_{ij}^k$：平面位置（偏移）

**在单个优化周期内，这些值是固定的。**

## 3. $\gamma_{ij}$ 调整的是什么？

| 调整对象 | 说明 |
|----------|------|
| ❌ 分割平面位置 | 不变 |
| ❌ 分割平面方向 | 不变 |
| ✅ 穿越边界的"惩罚力度" | 改变 |

## 4. 类比理解

```
分割平面 = 一堵墙
γ_ij = 墙的"硬度/排斥力强度"

调整 γ_ij：
- 不是移动墙的位置
- 而是改变"撞墙的代价"
```

| 左侧 ($\theta > 0$) | 右侧 ($\theta < 0$) |
|---------------------|---------------------|
| $\gamma_{ij}$ 增大 | $\gamma_{ij}$ 减小 |
| 墙"更硬" | 墙"更软" |
| 推得更远 | 可以靠近 |

## 5. 右手定则的真实效果

```
        左墙（变硬，推得更远）
             ↑
             |
    目标 ←---●
             |
             |
        右墙（变软，可靠近）
             ↓
```

**结果**：机器人被左侧"硬墙"推得更远，可以向右侧"软墙"靠近 → 整体向右移动

## 6. 完整过程

```
t 时刻：
  预定轨迹 P̄_i → 分割平面 a_ij, b_ij（固定）
  调整 γ_ij → 改变边界惩罚
  求解优化 → 得到新位置 p_i^K

t+1 时刻：
  新预定轨迹 → 新分割平面（位置变了！）
  继续调整 γ_ij
  ...
```

**分割平面的变化是由轨迹变化引起的，不是 $\gamma_{ij}$ 直接旋转平面。**

## 7. 一句话总结

> **$\gamma_{ij}$ 不旋转分割平面，而是非对称地调整左右边界对机器人的"排斥强度"，导致机器人向软边界一侧移动。**
