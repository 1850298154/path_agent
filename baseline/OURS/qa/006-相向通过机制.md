# 相向而行如何通过？—— 右手定则的核心作用

## 1. 问题场景

```
机器人A →     ← 机器人B
目标B          目标A
```

两机器人**相向而行**，θ ≈ 0，如何通过？

## 2. 关键洞察

**相向时 θ ≈ 0，确实没有初始侧向力！**

但右手定则有**两阶段作用**：

### 阶段1：微小扰动产生侧移

| 来源 | 作用 |
|------|------|
| 初始位置差异 | 两机器人不完全在一条直线上 |
| 数值误差 | 优化求解的微小偏差 |
| 目标位置约束 | "三个或更多机器人目标不共线"条件 |

**一旦产生微小侧移，θ 就不再等于 0！**

### 阶段2：右手定则放大侧移

```
假设A略微偏左，B略微偏右（微小扰动）：

对A：B在其右前方，θ_A < 0
  → γ_AB < γ_0 → 右侧推力弱
  → A继续向右靠

对B：A在其左前方，θ_B > 0
  → γ_BA > γ_0 → 左侧推力强
  → B继续向左靠

结果：侧移被放大！A右移，B左移
```

## 3. 图示过程

```
初始（相向）：
    A →        ← B
   θ=0        θ=0
   （无侧向力）

微小扰动后：
    A →  ↗    ↖  ← B
   θ<0          θ>0
   右弱         左强

放大后：
    A →      ← B
      ↘      ↙
     右移    左移

最终通过：
    A →          ← B
      ──→  ←──
         安全通过
```

## 4. 为什么不会撞上？

**两个机器人的右手定则方向相反！**

| 机器人 | 视角 | θ | 效果 |
|--------|------|---|------|
| A | B在我右前方 | θ_A < 0 | 向右避让 |
| B | A在我左前方 | θ_B > 0 | 向左避让 |

**A向右，B向左 → 背道而驰 → 不会相撞！**

## 5. 力学视角

```
对A的力平衡：
  F_吸引（向目标/向右）
  + F_排斥_B（向左，但因γ小而弱）
  = 净向右的力

对B的力平衡：
  F_吸引（向目标/向左）
  + F_排斥_A（向右，但因γ大而强）
  = 净向左的力
```

## 6. 关键：方向一致性

**所有机器人都遵循"右手定则"，保证了避让方向一致。**

```
如果A向左避让、B也向左避让 → 可能相撞
但右手定则保证：A右移、B左移 → 背道而驰
```

## 7. 与"旋转力"的区别

| 方法 | 机制 |
|------|------|
| 旋转力 | 给机器人施加切向力，使其绕行 |
| 右手定则 | 非对称调整排斥力，使机器人侧移 |

**本质相同**：都是产生侧向运动趋势

**实现不同**：
- 旋转力：直接施加力
- 右手定则：通过调整边界位置间接实现

## 8. 一句话总结

> **相向时 θ ≈ 0 无侧向力，但微小扰动产生侧移后，右手定则放大侧移，且两机器人避让方向相反（一左一右），保证安全通过。**
