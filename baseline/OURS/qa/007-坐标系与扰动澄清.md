# 坐标系定义与扰动类型

## 1. 坐标系定义（重要纠正）

**x 轴是"到目标方向"，不是"到对方方向"！**

```
正确理解：

对机器人 A：
  x 轴 = A → 目标A 的方向
  θ_AB = (A→目标A) 与 (A→B) 的夹角

对机器人 B：
  x 轴 = B → 目标B 的方向
  θ_BA = (B→目标B) 与 (B→A) 的夹角
```

## 2. 相向场景的正确分析

```
目标B                     目标A
  ↑                         ↑
  |                         |
  |    A →        ← B       |
  |   (向目标B)   (向目标A)  |
```

**对 A 而言**：
- x 轴方向：A → 目标B（向右）
- B 的位置：在 A 的正前方
- θ_AB ≈ 0（因为 A→目标B 和 A→B 几乎同向）

**对 B 而言**：
- x 轴方向：B → 目标A（向左）
- A 的位置：在 B 的正前方
- θ_BA ≈ 0（因为 B→目标A 和 B→A 几乎同向）

## 3. 扰动类型

**是的，主要是位置扰动。**

| 扰动类型 | 说明 |
|----------|------|
| **位置扰动** | 两机器人初始位置不完全在一条直线上 |
| 数值误差 | 优化求解的浮点误差 |
| 时间异步 | 两机器人决策时刻的微小差异 |

### 位置扰动示例

```
理想直线（θ = 0，无侧移）：
    A → ← B
    ─────────

实际位置（有偏差）：
      A →
        \
         \
          ← B
         /
        /

θ 不再为 0，产生侧向力
```

## 4. 扰动后的角度变化

假设 B 略微偏右（从 A 视角）：

```
对 A：
  x 轴 = A → 目标（向右）
  B 在：右前方偏一点
  θ_AB < 0（略微负）
  → γ_AB < γ_0
  → 右侧墙弱 → A 向右靠

对 B：
  x 轴 = B → 目标（向左）
  A 在：左前方偏一点
  θ_BA > 0（略微正）
  → γ_BA > γ_0
  → 左侧墙强 → B 向左靠
```

## 5. 关键图示

```
        目标A
          ↑
          |
          |
    B ←───┼───→ A
          |      \
          |       \ 右移
          |        \
        目标B      ↓
                   右移后

A 向右避让，B 向左避让
方向相反，安全通过
```

## 6. 一句话总结

> **x 轴是"到目标方向"（不是到对方），扰动主要是位置扰动（两人不在一条直线上），扰动后 θ ≠ 0，右手定则开始生效。**
