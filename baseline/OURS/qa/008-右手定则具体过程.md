# 右手定则具体过程详解

## 1. 场景设定

```
目标A（左）            目标B（右）
    ↑                      ↑
    |                      |
    |   ← B            A → |
    |                      |
```

- **A 向右移动**（目标在右边）
- **B 向左移动**（目标在左边）
- 两人相向而行

## 2. 扰动后产生侧移

假设 **B 略微在 A 的左边**（从 A 视角，θ_AB > 0）：

```
              目标B
                ↑
                |
            A → |  （A 向右移动）
               /|
              / | θ_AB > 0（B 在 A 左手边）
             /  |
            B   |
           /    |
    ← B   /     |
        目标A  ↓
```

## 3. 对 A 的分析

| 参数 | 计算 | 结果 |
|------|------|------|
| B 的位置 | 在 A 的**左手边** | θ_AB > 0 |
| γ_AB | γ₀ × e^(ρ×sinθ) | **增大** (因为 sinθ > 0) |
| w_AB | 惩罚大 → w 增大 | **增大** |
| 墙位置 | b + w | **被推远**（向左推） |
| A 的运动 | 被左侧墙推开 | **向右移动** ✅ |

## 4. 对 B 的分析

同时，从 B 的视角：

```
B 的 x 轴 = B → 目标A（向左）
A 在 B 的右手边（从 B 视角）
θ_BA < 0
```

| 参数 | 计算 | 结果 |
|------|------|------|
| A 的位置 | 在 B 的**右手边** | θ_BA < 0 |
| γ_BA | γ₀ × e^(ρ×sinθ) | **减小** (因为 sinθ < 0) |
| w_BA | 惩罚小 → w 减小 | **减小** |
| 墙位置 | b + w | **被拉近**（墙变近） |
| B 的运动 | 右侧墙弱，可靠近 | **向左移动** ✅ |

## 5. 你的理解纠正

| 你说的 | 更准确的说法 |
|--------|-------------|
| "目标左边的B增大惩罚" | B 在 A 的**左手边** → γ 增大 → 墙被推远 |
| "目标在B的右边（放宽平面）" | 从 B 视角，A 在**右手边** → γ 减小 → 墙变近 |

**关键**：左右是相对于"到目标方向"而言，不是全局坐标。

## 6. 完整过程图示

```
初始：相向而行
    ← B        A →
    ───────────────
    θ = 0，无侧向力

扰动后（B 略偏左）：

    ← B
       \
        \    A →
         \  /
          \/
          /\
         /  \
        /    \ 右移
    左移      ↓
     ↑

对 A：左侧墙强（被推远）→ 向右
对 B：右侧墙弱（可靠近）→ 向左

结果：两人背道而驰，安全通过
```

## 7. 核心机制表格

| 机器人 | 对方位置 | θ | γ | w | 墙位置 | 运动方向 |
|--------|----------|---|---|---|--------|----------|
| A | 左手边 | θ > 0 | 增大 | 增大 | 推远 | **向右** |
| B | 右手边 | θ < 0 | 减小 | 减小 | 拉近 | **向左** |

## 8. 一句话总结

> **B 在 A 左手边 → A 的 γ 增大 → 左墙推远 → A 向右移；同时 A 在 B 右手边 → B 的 γ 减小 → 右墙拉近 → B 向左移。两人背道而驰。**
